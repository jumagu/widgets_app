# Widgets App

A Flutter demonstration application showcasing various Flutter widgets and UI components. This educational project includes examples of buttons, cards, animations, infinite scroll, theme management, and more.

## Demo



## Features

- **Buttons**: Various button types and styles
- **Cards**: Styled card components
- **Progress Indicators**: General and controlled progress indicators
- **Snackbars**: Toast notifications and messages
- **Animated Container**: Stateful animated widgets
- **UI Controls + Tiles**: Checkboxes, switches, radio buttons, and tiles
- **App Tutorial**: Introduction/onboarding screens
- **Infinite Scroll**: List with pull-to-refresh functionality
- **Counter**: Simple counter with state management
- **Theme Controller**: Dark mode and color theme customization

## Installation

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) (3.8.1 or higher)
- Dart SDK (included with Flutter)
- Android Studio / Xcode / VS Code with Flutter extensions

### Steps

1. Clone the repository:
```bash
git clone https://github.com/jumagu/widgets_app
cd widgets_app
```

2. Install dependencies:
```bash
flutter pub get
```

3. Run the app:
```bash
flutter run
```

### Available Commands

- `flutter run` - Run the app in debug mode
- `flutter build apk` - Build Android APK
- `flutter build appbundle` - Build Android App Bundle
- `flutter build ios` - Build iOS app (requires macOS)
- `flutter build windows` - Build Windows desktop app
- `flutter test` - Run tests
- `flutter clean` - Clean build artifacts

## Dependencies

- `flutter` - Flutter SDK
- `flutter_riverpod` (^2.6.1) - State management solution
- `go_router` (^16.0.0) - Declarative routing package
